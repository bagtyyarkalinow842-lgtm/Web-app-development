## 📌 Функциональные требования

### 1. Пользовательский контур (Клиент)
* [ ] Регистрация и авторизация (Email + пароль, вход через OAuth / Telegram / Google).
* [ ] Восстановление доступа и подтверждение электронной почты.
* [ ] Личный кабинет пользователя (редактирование профиля, история активности, смена пароля).
* [ ] Полнотекстовый поиск с автодополнением и подсказками.
* [ ] Каталог с многоуровневой фильтрацией (по категориям, цене, рейтингу) и сортировкой.
* [ ] Добавление элементов в избранное / корзину с синхронизацией состояния.

### 2. Административный контур (Панель управления)
* [ ] Ролевая модель доступа (Admin, Manager, User).
* [ ] CRUD-операции над сущностями системы (создание, просмотр, редактирование, удаление).
* [ ] Просмотр базовой аналитики и логов действий пользователей.
