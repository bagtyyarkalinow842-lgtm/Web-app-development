# 📖 «Живая книга» — Рецензирование и комментарии к дипломным работам в реальном времени

> Веб-платформа для совместного анализа и рецензирования черновиков академических работ (ВКР, курсовых проектов, научных статей). Сервис позволяет студентам получать обратную связь по научному стилю и содержанию от сокурсников (включая анонимный режим), а преподавателям — утверждать исправления специальной «зеленой меткой».

## 📌 Функциональные требования к проекту

### 1. Модуль публикации и работы с документами

* [ ] Загрузка черновиков работ в форматах `.docx`, `.md` или вставка структурированного текста.
* [ ] Полноэкранный режим чтения и анализа текста с разбивкой на структурные разделы (Введение, Главы, Заключение, Список литературы).
* [ ] Настройки приватности работы: публичный доступ, доступ по ссылке, доступ только своей учебной группе или преподавателю.

### 2. Подсистема интерактивного комментирования (Core Feature)

* [ ] **Inline-комментирование:** выделение произвольного фрагмента/фразы текста курсором и открытие карточки замечания на боковой панели.
* [ ] **Категоризация заметок:** выбор типа ошибки при создании замечания (например: *«Научный стиль»*, *«Нарушение ГОСТ»*, *«Фактическая ошибка / Логика»*, *«Опечатка / Пунктуация»*).
* [ ] **Режим анонимности:** переключатель «Оставить комментарий анонимно» или под своим никнеймом для снятия барьера критики между студентами.
* [ ] **Ветки обсуждения (Threads):** возможность автора диплома ответить на замечание и прикрепить вариант исправления.

### 3. Модуль преподавателя («Зеленая метка»)

* [ ] Ролевая модель доступа: `Студент-автор`, `Рецензент (сокурсник)`, `Научный руководитель (Преподаватель)`.
* [ ] Механизм **«Зеленой метки»**: подтверждение преподавателем того, что замечание студента было обоснованным, а автор работы корректно внес исправление (статус *Resolved / Принято*).
* [ ] Прогресс-бар готовности диплома (процент устраненных замечаний от общего числа правок).

### 4. Синхронизация и Realtime

* [ ] Мгновенное отображение новых комментариев и реакций без перезагрузки страницы (через WebSockets / SSE).
* [ ] Индикация активных читателей текущей главы.

## 🛠 Технологический стек

| **Область** | **Технологии / Библиотеки** | **Обоснование выбора** |
| :--- | :--- | :--- |
| **Frontend** | React / Next.js, TypeScript | Высокая скорость рендеринга сложного DOM дерева и строгая типизация |
| **Стилизация** | Tailwind CSS, Lucide Icons | Гибкая верстка двухколоночного интерфейса (текст + сайдбар заметок) |
| **Работа с текстом** | TipTap / ProseMirror / Slate.js | Индустриальный стандарт для привязки диапазонов (Ranges) и выделения цитат |
| **Realtime-коммуникация** | Socket.IO / WebSockets | Мгновенная доставка комментариев и статусов «зеленой метки» |
| **Backend** | Node.js (NestJS / Express) *или* Python (FastAPI) | Поддержка асинхронных соединений и удобная валидация схем данных |
| **База данных** | PostgreSQL + Prisma ORM | Надежное хранение реляционных связей (пользователи → документы → комментарии → ответы) |
| **Кэш & Брокер сообщений** | Redis | Хранение сессий пользователей и очередей сообщений WebSocket |
| **Контейнеризация** | Docker, Docker Compose | Воспроизводимость окружения разработки и продакшена |
